# Publication checklist

- [x] All data is synthetic or public and clearly labeled.
- [x] No employer names, credentials, private URLs, or internal identifiers appear in files or history.
- [x] Commit messages describe the product change, not the portfolio-building process.
- [x] Tests and the full pipeline pass from a clean checkout.
- [x] Generated artifacts match the committed source.
- [x] Repository description and topics describe the technical work accurately.
- [x] Public repository view and commit history have been reviewed.
