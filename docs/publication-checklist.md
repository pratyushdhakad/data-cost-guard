# Publication checklist

- [ ] All data is synthetic or public and clearly labeled.
- [ ] No employer names, credentials, private URLs, or internal identifiers appear in files or history.
- [ ] Commit messages describe the product change, not the portfolio-building process.
- [ ] Tests and the full pipeline pass from a clean checkout.
- [ ] Generated artifacts match the committed source.
- [ ] Repository description and topics describe the technical work accurately.
- [ ] Public repository view and commit history have been reviewed.
